1. 자기력: 밀고 당기는 힘
자석 사이에 작용하는 힘을 자기력이라 한다.
다른 극끼리 → 끌어당김 (인력)
같은 극끼리 → 밀어냄 (척력)
2. 자석 주위의 자기장
자기장 = 자기력이 작용하는 공간
방향 = 그곳 나침반 N극이 가리키는 쪽
자기력선 : N극 → S극
자기장의 방향 · 세기를 나타낸 선
선이 촘촘할수록 → 자기장이 세다
자석에서 멀수록 → 자기장이 약해진다
3. 전류가 만드는 자기장
전류가 없을 때: 나침반 N극은 북쪽
코일에 전류 → 막대자석 같은 자기장
전류 세기 ↑ → 자기장 세기 ↑
(같은 코일에서 비교)
전류 반대 → 자기장 반대
(N극 · S극이 바뀜)
전류 끊음 → 나침반은 다시 남북 방향
전류가 흐르는 동안은 코일의 자기장만 생각한다(지구 자기장 영향 생략)
4. 오른손 규칙 — 전류에 의한 자기장의 방향
① 직선 도선: 엄지 = 전류 / 감은 네 손가락 = 자기장
전류: 종이 밖으로 나오는 방향
→ 자기장은 시계 반대 방향
※ 전류가 흐를 때는 지구 자기장 영향 생략
전류: 종이 안으로 들어가는 방향
→ 자기장은 시계 방향
② 원형 도선: 네 손가락 = 전류 / 엄지 = 중심의 자기장
엄지 방향: 원이 이루는 면에 수직
③ 코일: 네 손가락 = 전류 / 엄지 = N극 쪽
엄지 → 코일 내부 자기장의 방향
(앞쪽 도선의 전류가 위 → 엄지는 왼쪽 → 왼쪽이 N극)
5. 전자석 = 코일 + 철심
전류가 흐를 때만 자석의 성질을 띤다.
영구 자석과 달리 켜고 끄기 · 세기 · 극을 조절
전류의 세기 ↑ → 자기장 세기 ↑
전류의 방향을 바꾸면 → 자기장 방향 반대
이용: 고철 기중기 · 자기 부상 열차 · 스피커 · 전동기

① 자기력선은 S극에서 나와 N극으로 들어간다.
→ 자석 바깥에서 N극 → S극
② 코일에 흐르는 전류의 방향을 바꾸어도 코일의 N극·S극은 그대로이다.
→ 전류 반대 → 자기장 반대, N·S가 바뀐다
③ 직선 도선의 전류가 종이 면에서 나오는 방향이면 자기장은 시계 반대 방향이다.
→ 엄지 = 전류(⊙), 감은 손가락 = 시계 반대 방향
확인 문제 1
⏸ 멈추고 풀어 보세요
그림과 같이 코일에 화살표 방향으로 전류가 흐르고, 코일의 왼쪽 축 위에 점 P가 있다.
이에 대한 설명으로 옳은 것은? (단, 지구 자기장은 생각하지 않는다.)
① 코일의 왼쪽 끝은 S극이다.
② 코일 내부의 자기장은 오른쪽을 향한다.
③ P에 놓은 나침반의 N극은 코일 쪽(오른쪽)을 가리킨다.
④ 전류의 방향을 반대로 하면 코일의 왼쪽 끝은 S극이 된다.
⑤ 전류를 끊어도 코일은 계속 자석의 성질을 띤다.
정답 ④
앞쪽 도선 전류 ↑ → 엄지 왼쪽
왼쪽 끝 = N극
코일 내부 자기장 ← 왼쪽
P: N극에서 나가는 쪽 → 왼쪽
전류 반대 → 극 반대

1. 자석과 자기장
다른 극 인력 · 같은 극 척력
자기장 방향 = 나침반 N극
자기력선 N극 → S극
촘촘할수록 세다
멀수록 약하다
2. 전류의 자기장
직선: 엄지 전류 / 손가락 자기장
⊙ 나옴 → 반시계
⊗ 들어감 → 시계
코일: 손가락 전류 / 엄지 N극
전류 세기 ↑ → 자기장 세기 ↑
전류 반대 → N·S 바뀜
